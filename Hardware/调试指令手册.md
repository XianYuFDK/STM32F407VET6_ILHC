# STM32F407VET6_ILHC 调试指令手册

本文档用于 USART1 调试串口的在线调试，包含底盘、OPS 坐标清零、DM-J4310 电机调试指令及 VOFA+ 数据通道说明。

---

## 1. 调试串口连接

| 项目 | 配置 |
|---|---|
| 调试串口 | USART1 |
| TX | PA9 |
| RX | PA10 |
| 波特率 | 115200 |
| 数据格式 | 8N1 |
| 发送换行 | `\r` 或 `\n` |
| 建议上位机 | VOFA+ / 串口助手 |

VOFA+ 设置：

1. 打开 VOFA+。
2. 选择串口协议为 `JustFloat`。
3. 选择调试串口：`115200 / 8N1`。
4. 开始接收后即可看到第 3 节中的通道数据。

---

## 2. 命令发送规则

- 每行只能发送一条命令。
- 命令名不区分大小写，例如 `DMEN` 和 `dmen` 等价。
- `=` 两侧可以不加空格。
- 参数必须使用浮点数格式，例如 `3.14`、`-2.0`、`0.5`。
- 发送完成后通过回车或换行结束。

## 4. 通用调试命令

### STOP
```text
STOP
```
停止底盘四个 ZDT_X42S 电机、取消 GOTO，并失能正在调试的 DM 电机。

### ZERO
```text
ZERO
```
以当前 OPS 坐标作为新的本地零点，不清除 OPS 模块数据。

注意：`ZERO` 只影响 OPS 底盘坐标，不清零 DM 电机。
执行 ZERO 前固件会先取消 GOTO 并停止底盘，避免坐标系突变导致误动作。

### GOTO（全局定位移动）
```text
GOTO=1200,800,90
GOTO=1200,800
```
- 参数依次为：目标 X（mm）、目标 Y（mm）、目标航向角（°，OPS 坐标系）
- 第 3 个参数可省略，省略时保持当前航向
- 收到后底盘以当前调试限幅速度（XVMAX/ZVMAX）连续移动到目标点，
  每 20ms 执行一步 P 控制（`MecanumControl_GotoOPS`），到位后停止并清除目标
- 再次发送 `GOTO` 可随时更换目标；发送 `STOP` 立即停止并取消目标
- 上位机"比赛场地地图"页点击地图即自动下发此命令

## 5. 底盘调试命令

### 5.1 定位 P 系数

| 命令 | 含义 | 默认值 | 范围 |
|---|---|---|---|
| `KPX=2.3` | 设置 X 轴 P 系数 | 2.3 | 0.0 ~ 50.0 |
| `KPY=2.3` | 设置 Y 轴 P 系数 | 2.3 | 0.0 ~ 50.0 |
| `KPZ=9.0` | 设置航向角 P 系数 | 9.0 | 0.0 ~ 50.0 |
| `GOTO=x,y,z` | OPS 全局定位移动到目标点 | — | x/y ±3000 mm |
| `PING` | 调试动作运行心跳 | — | 建议每 200ms 发送 |

执行 GOTO 或 DM 调试期间，固件超过 1 秒未收到任何命令或 `PING`，会自动停车并失能 DM。

### 5.2 速度限幅

| 命令 | 含义 | 默认值 | 范围 |
|---|---|---|---|
| `XVMAX=1600` | X/Y 最大定位控制量 | 1600 | 0 ~ 3000 |
| `ZVMAX=750` | 航向最大定位控制量 | 750 | 0 ~ 3000 |
| `XVMIN=5` | X/Y 最小补偿量 | 5 | 0 ~ 100 |
| `ZVMIN=5` | 航向最小补偿量 | 5 | 0 ~ 100 |

示例：

```text
KPX=2.0
KPY=2.0
KPZ=8.0
XVMAX=1200
ZVMAX=600
```

### 5.3 底盘/OPS 调试流程

```text
# 1. 观察当前 OPS 坐标
# 2. 设置当前点为零点
ZERO

# 3. 调节定位参数
KPX=2.0
KPY=2.0
KPZ=8.0
XVMAX=1200
ZVMAX=600

# 4. 需要停止底盘时
STOP
```

## 6. DM-J4310-2EC 电机调试命令

调试串口目前默认调试一个 DM 电机，默认电机 ID 为 `1`。

### 6.1 基础命令

| 命令 | 含义 |
|---|---|
| `DMID=1` | 设置 DM 电机 ID，范围 1 ~ 0x6FF |
| `DMEN` | 写入当前控制模式寄存器，使能电机，并开始周期下发控制帧 |
| `DMOFF` | 失能 DM 电机，停止下发控制帧 |
| `DMSTOP` | `DMOFF` 的别名 |
| `DMZERO` | 将 DM 电机当前位置保存为零点 |

### 6.2 控制模式

| 命令 | 含义 |
|---|---|
| `DMMODE=1` | MIT 模式 |
| `DMMODE=2` | 位置速度模式 |

发送 `DMEN` 时，驱动会自动向寄存器 10 写入当前模式。

### 6.3 MIT 模式参数

| 命令 | 含义 | 范围 |
|---|---|---|
| `DMPOS=0.0` | 目标位置，单位 rad | -12.5 ~ 12.5 |
| `DMVEL=2.0` | 目标速度，单位 rad/s | -30.0 ~ 30.0 |
| `DMKP=2.0` | Kp | 0.0 ~ 500.0 |
| `DMKD=1.0` | Kd | 0.0 ~ 5.0 |
| `DMTOR=0.0` | 前馈力矩，单位 Nm | -10.0 ~ 10.0 |

### 6.4 位置速度模式参数

| 命令 | 含义 | 范围 |
|---|---|---|
| `DMPOS=3.14` | 目标位置，单位 rad | -12.5 ~ 12.5 |
| `DMVEL=2.0` | 目标最大速度，单位 rad/s | -30.0 ~ 30.0 |

位置速度模式下会忽略 `DMKP`、`DMKD`、`DMTOR`。

## 9. 注意事项

1. DM 电机默认不会自动使能，必须发送 `DMEN` 才会开始发送控制帧。
2. `DMPOS`、`DMVEL` 等参数会先保存，只有 `DMEN` 后才会持续下发。
3. 调试过程中请不要同时移动底盘和 DM 电机，避免相互影响。
4. 调节 DM 电机时建议先保持 `DMOFF`，确认参数后再使能。
5. `P_MAX / V_MAX / T_MAX` 必须与达妙调试工具中的电机参数一致。
6. 若 DM 电机出现 `0x0D` 通信丢失，请检查 CAN1 线缆、电机供电和电机 ID。
7. 急停时发送：
   ```text
   DMOFF
   ```
8. 底盘急停时发送：
   ```text
   STOP
   ```

# 28/35步进调试扩展（2026-09-10）

USART1新增单次请求（CR/LF结束），由任务提交CAN，不在接收中断发送。

| 命令 | 参数 |
| --- | --- |
| `S35MOVE=1000,50` | 高度0.1mm整数、线速度mm/s整数；高度430–2030，速度1–2184 |
| `S28MOVE=2000,50` | 半径0.1mm整数、线速度mm/s整数；半径1200–2860，速度2–65535 |
| `S35RAW=0,1000,100` / `S28RAW=0,1000,100` | 方向0/1、绝对位置计数0–UINT32_MAX、RPM 1–65535 |
| `S35HOME` / `S28HOME` | 执行驱动原有回零命令，不等待回零完成 |
| `S35CANCEL` / `S28CANCEL` | 撤销该电机待发请求，不是停机命令 |

机械换算采用stepper_2835驱动原车标定，协议范围不是机构允许速度。
每台电机保留最新待发请求；邮箱忙最多重试1秒，HAL_ERROR丢弃请求而不重试。
STOP和失联清除待发请求，不能停止已经执行的28/35运动；未推定未验证的停机协议。
原24通道遥测保持不变，没有新增文本ACK或28/35到位反馈，发送不等于执行成功。
Qt地图采用启停区1中心为零、左+X、上+Y；控制台GOTO与原始遥测仍为OPS坐标。


## 底盘手动控制（2026-09-10）

Qt「底盘调参」新增按住运行的手动按钮：前后、横移、原地旋转、前进/后退叠加左右旋转；也可填写三个有符号速度分量后按住组合运动。默认平移60 RPM、旋转30 RPM，每轴范围-300..300 RPM。这些是轮速混合分量，旋转值不是角速度，三轴叠加单轮最多900 RPM，不使用GOTO的XVMAX/ZVMAX。

地址按俯视、车头朝上：左前1、右前2、左后3、右后4。实际转向沿用已有麦轮速度解算；第一次低速核对运动方向，可用「前后反向/左右反向/旋转反向」修正手动按键。这些选项仅作用于本次界面手动控制，不改变GOTO或保存到Flash。

协议：`MANUAL=vx,vy,w`，严格三个整数，范围各-300..300，以换行结束；例如`MANUAL=60,0,30`为前后与旋转分量叠加。主机按住期间约100ms续发，固件350ms未收到有效MANUAL即在下次任务服务停车，PING不续期。无OPS也可手动运行。有效MANUAL取消GOTO，有效GOTO结束手动；STOP/ZERO取消手动。`MANUAL=0,0,0`仅停止底盘；界面松开使用全局STOP，因此也会失能DM并取消28/35待发请求。

松开、切页、窗口失去激活、断开、关闭时结束手动续发并请求STOP；线程或串口故障靠固件独立超时兜底。停车时间受现有任务周期、串口阻塞影响，不是硬实时保证。上位机显示的是发送请求，没有固件手动状态ACK。串口遥测保持24通道不变。

Qt新增按钮；原版上位机可在终端发送该命令，其模拟器同步支持手动运动及超时。真实使用需要烧录新增MANUAL支持的F407固件，OPS固件不因本功能而修改。本次测试不连接设备、不发送实际运动命令。


## OPS 安装偏心补偿（2026-09-10）

F407的`Hardware/ops.c`默认补偿车体后偏50mm、左偏60mm，即`rx=-50mm, ry=+60mm`。rx/ry表示从四驱动轮几何中心指向OPS两条滚动测量直线交点的车体向量；前为+X、左为+Y。与当前OPS模式2按此前约定接轮、yaw逆时针为正配套；实际方向反向时要先确认原始OPS轴和yaw，GUI手动电机反向开关不会改变OPS坐标。

补偿由F407执行一次，不修改OPS板固件。公式：`中心相对位移 = 原始OPS位移 - (R(yaw)-R(参考yaw))*r`。首帧航向是未ZERO时的参考；建议上电保持静止并收到有效OPS数据后ZERO。ZERO保存原始位置和当时yaw，保留工程既有坐标反号：`GetPosition = -(原始相对位移 - 偏心旋转位移)`。yaw不置零。`OPS_GetAbsolutePosition()`和`OPS_GetData()->frame`仍是原始OPS数据；未ZERO的`OPS_GetPosition()`也会补偿。`OPS_ClearZero()`切回首帧参考的补偿坐标。`OPS_SetOrigin(x,y)`的输入仍是原始OPS坐标，调用当时yaw作为该零点的补偿参考。

### 上位机操作

1. 烧录本次F407固件，打开Qt「底盘调参」顶部「OPS安装偏心补偿」。前后=-50、左右=60，单位mm。
2. 点击「应用补偿并置零」。界面停止手动续发、请求STOP，然后发送成对参数。固件停止底盘并取消手动/GOTO，应用补偿；已有有效OPS帧时同时重新置零，因此原来的地图目标/坐标原点需要重新确认。
3. 用手动原地旋转，在90°、180°等位置停下，查看同页中心X/Y和距零点距离。每次修改参数后重新从零点做同一组试验，可按1mm小步调整，顺逆时针都检查。仅看转满360°的终点不足以判断偏心是否消除。
4. 「保存到电脑」保存当前输入的两项参数为JSON；「加载文件」只填入控件，不自动下发，需再点击应用。「填入初始值」同样不自动下发。填0,0后应用可比较不补偿效果。

协议：`OPSOFFSET=-50.0,60.0\n`，严格两个十进制数，每项范围±500mm，支持负号/小数，不接受指数、NaN、额外字段或尾随字符。中断只更新成对请求，任务停车后应用，不在中断中做三角运算。该命令即使手动输入也会取消底盘动作并重新置零；原版上位机可通过命令终端使用。Qt和原版模拟器均支持，模拟器假设真实安装就是后50/左60，演示残差，不代替实车验证。

调参值只保存在F407 RAM，断电恢复后50/左60的固件默认值；电脑JSON不等于Flash保存。当前24通道协议不扩展，没有参数ACK/回读，界面明确显示“已请求”，以实车旋转遥测验证。位置遥测现每次发送前刷新，手动控制或静止时也能观察补偿结果。

验证：`python Tests/hardware/test_ops_offset.py`验证真实C函数的旋转、平移、非零航向ZERO、原始接口、越界拒绝和中断状态恢复；Qt `python -m unittest -v test_debugger`覆盖应用、文件读写和模拟残差；固件EIDE编译。没有实车/烧录验证。


## 张大头底盘单电机限时测试（ZDT）

格式：`ZDT=地址,有符号转速,运行秒数`，以换行结束；地址1~4，转速-300~300 RPM，秒数1~5。
正数方向位0，负数方向位1；实际轮子正反转与安装有关。速度单位以驱动器Emm配置为准。

```text
ZDT=3,50,2
ZDT=3,-50,2
ZDT=4,50,2
ZDT=4,-50,2
STOP
```

每条分别发送，等上一次自动停止再测试下一条。先架空底盘，退出上位机手动控制，使用自定义指令发送入口；115200、8N1、文本发送并追加换行。单片机收到后先停止四轮，再重新使能指定电机，等待至少100ms，以加速度参数100运行指定秒数，最后发送FE98专用停止帧。无需OPS，也无需连接其他电机。

这是有界单次测试，不需要周期重发或PING；最长5秒后自动停止。测试期间忽略新的ZDT/MANUAL/GOTO，STOP、ZERO、OPSOFFSET会取消测试。测试结束后新的手动指令可重新驱动车轮，因此不要同时按住手动控制按钮。转速0只停车，不使能。

仍保持24通道JustFloat遥测，不新增ASCII成功回执；上位机TX日志不代表单片机执行成功，也不代表电机应答。固件必须重新烧录，接线为UART4：PA0 TX接驱动器RX，共地；PA1为MCU RX。当前电机驱动没有ACK解析，串口发送失败也无法保证物理停车，调试时保留断电手段。


### ZDT文字应答（新增，以本节为准）

收到以换行结束的ZDT命令后自动暂停JustFloat遥测，改为USART1 DMA发送ASCII应答。发送`VOFA`并追加换行恢复24通道遥测。切换时可能仍有一帧旧遥测在途。

- `ACK ZDT ACCEPTED`：格式及范围合法，单片机已接收并入队。
- `ERR ZDT BUSY`：测试正在执行或有停止等请求待处理，本条未执行。
- `ERR ZDT FORMAT: ZDT=1..4,-300..300,1..5`：格式/参数错误，未执行。
- `ACK ZDT RUN_REQUESTED (NO MOTOR ACK)`：任务已调用指定电机速度驱动接口。
- `ACK ZDT STOP_REQUESTED (NO MOTOR ACK)`：时间到或零速请求，已调用停车接口。
- `ACK ZDT CANCELLED (NO MOTOR ACK)`：STOP/ZERO/安装参数请求取消测试。

这些都是单片机调试应答，不是电机回复。当前底层发送接口不返回HAL状态，因此REQUESTED不保证UART发送成功，更不保证电机执行成功。事件队列可缓存15条应答，满时丢新应答，不影响停止逻辑。上位机文本显示模式查看即可；完成测试后用VOFA恢复波形。无任何应答时先检查新固件、USART1接线及命令换行。


### UART4电机真实回包调试（新增）

新固件在首次电机使能前启动UART4逐字节中断接收。PA0接驱动器RX、PA1接驱动器TX并共地，115200/8N1。仅支持F3/F6/FE四字节应答；驱动器需允许返回应答并使用固定6B校验配置。

发送`ZDT=4,50,2`加换行后，文字模式会显示收到的真实数据，例如：
```text
ZDT RX: 04 F3 02 6B
ZDT RX: 04 F6 02 6B
ZDT RX: 04 FE 02 6B
```
02表示命令正确应答，非机械运动到位。E2、EE或其他原始状态码原样输出，不冒充成功。RX可能与MCU ACK交错，也可能包括测试切换时其他轮子的停车回复；必须查看地址和功能码。

测试开始500ms内未收到目标地址任何有效控制应答时输出`WARN ZDT NO_VALID_REPLY IN 500MS`；仅为本次电机有无回复的检查，不是每条命令的独立超时判定，也不代表电机必然离线。晚到回复继续显示。超时不会延长测试，也不改变停车流程。

仍可用STOP取消，用VOFA恢复波形。UART4错误由任务重启接收，接收队列及文本队列各最多15帧/条，过载丢新数据。正常VOFA模式排空回包不输出文字。当前不支持长查询帧解析，不报告实际速度；电机TX线路必须连接才能看到真实应答。
