# STM32F407VET6_ILHC 调试指令手册

本文档用于 USART1 调试串口的在线调试，包含底盘、OPS 坐标清零、DM-J4310 电机调试指令及 VOFA+ 数据通道说明。

---

## 1. 调试串口连接

| 项目 | 配置 |
|---|---|
| 调试串口 | USART1 |
| TX | PA9 |
| RX | PA10 |
| 波特率 | 115200 |
| 数据格式 | 8N1 |
| 发送换行 | `\r` 或 `\n` |
| 建议上位机 | VOFA+ / 串口助手 |

VOFA+ 设置：

1. 打开 VOFA+。
2. 选择串口协议为 `JustFloat`。
3. 选择调试串口：`115200 / 8N1`。
4. 开始接收后即可看到第 3 节中的通道数据。

---

## 2. 命令发送规则

- 每行只能发送一条命令。
- 命令名不区分大小写，例如 `DMEN` 和 `dmen` 等价。
- `=` 两侧可以不加空格。
- 参数必须使用浮点数格式，例如 `3.14`、`-2.0`、`0.5`。
- 发送完成后通过回车或换行结束。

## 3. VOFA+ JustFloat 输出通道

当前共 24 个 float 通道：

标准帧格式为 `24×float32 小端 + 00 00 80 7F`，共 100 字节，不包含额外帧头。

| 9 | XYVmax | X/Y 最大控制限幅 |
| 10 | ZVmax | 航向最大控制限幅 |
| 11 | SpeedTarget[0] | 1 号轮目标速度 |
| 12 | dm_id | DM 电机 ID |

| 14 | dm_vel | DM 电机实际速度 |
| 15 | dm_torque | DM 电机实际力矩 |

## 4. 通用调试命令

### STOP
```text
STOP
```
停止底盘四个 ZDT_X42S 电机、取消 GOTO，并失能正在调试的 DM 电机。

### ZERO
```text
ZERO
```
以当前 OPS 坐标作为新的本地零点，不清除 OPS 模块数据。

注意：`ZERO` 只影响 OPS 底盘坐标，不清零 DM 电机。
执行 ZERO 前固件会先取消 GOTO 并停止底盘，避免坐标系突变导致误动作。

### GOTO（全局定位移动）
```text
GOTO=1200,800,90
GOTO=1200,800
```
- 参数依次为：目标 X（mm）、目标 Y（mm）、目标航向角（°，OPS 坐标系）
- 第 3 个参数可省略，省略时保持当前航向
- 收到后底盘以当前调试限幅速度（XVMAX/ZVMAX）连续移动到目标点，
  每 20ms 执行一步 P 控制（`MecanumControl_GotoOPS`），到位后停止并清除目标
- 再次发送 `GOTO` 可随时更换目标；发送 `STOP` 立即停止并取消目标
- 上位机"比赛场地地图"页点击地图即自动下发此命令

## 5. 底盘调试命令

### 5.1 定位 P 系数

| 命令 | 含义 | 默认值 | 范围 |
|---|---|---|---|
| `KPX=2.3` | 设置 X 轴 P 系数 | 2.3 | 0.0 ~ 50.0 |
| `KPY=2.3` | 设置 Y 轴 P 系数 | 2.3 | 0.0 ~ 50.0 |
| `KPZ=9.0` | 设置航向角 P 系数 | 9.0 | 0.0 ~ 50.0 |
| `GOTO=x,y,z` | OPS 全局定位移动到目标点 | — | x/y ±3000 mm |
| `PING` | 调试动作运行心跳 | — | 建议每 200ms 发送 |

执行 GOTO 或 DM 调试期间，固件超过 1 秒未收到任何命令或 `PING`，会自动停车并失能 DM。

### 5.2 速度限幅

| 命令 | 含义 | 默认值 | 范围 |
|---|---|---|---|
| `XVMAX=1600` | X/Y 最大定位控制量 | 1600 | 0 ~ 3000 |
| `ZVMAX=750` | 航向最大定位控制量 | 750 | 0 ~ 3000 |
| `XVMIN=5` | X/Y 最小补偿量 | 5 | 0 ~ 100 |
| `ZVMIN=5` | 航向最小补偿量 | 5 | 0 ~ 100 |

示例：

```text
KPX=2.0
KPY=2.0
KPZ=8.0
XVMAX=1200
ZVMAX=600
```

### 5.3 底盘/OPS 调试流程

```text
# 1. 观察当前 OPS 坐标
# 2. 设置当前点为零点
ZERO

# 3. 调节定位参数
KPX=2.0
KPY=2.0
KPZ=8.0
XVMAX=1200
ZVMAX=600

# 4. 需要停止底盘时
STOP
```

## 6. DM-J4310-2EC 电机调试命令

调试串口目前默认调试一个 DM 电机，默认电机 ID 为 `1`。

### 6.1 基础命令

| 命令 | 含义 |
|---|---|
| `DMID=1` | 设置 DM 电机 ID，范围 1 ~ 0x6FF |
| `DMEN` | 写入当前控制模式寄存器，使能电机，并开始周期下发控制帧 |
| `DMOFF` | 失能 DM 电机，停止下发控制帧 |
| `DMSTOP` | `DMOFF` 的别名 |
| `DMZERO` | 将 DM 电机当前位置保存为零点 |

### 6.2 控制模式

| 命令 | 含义 |
|---|---|
| `DMMODE=1` | MIT 模式 |
| `DMMODE=2` | 位置速度模式 |

发送 `DMEN` 时，驱动会自动向寄存器 10 写入当前模式。

### 6.3 MIT 模式参数

| 命令 | 含义 | 范围 |
|---|---|---|
| `DMPOS=0.0` | 目标位置，单位 rad | -12.5 ~ 12.5 |
| `DMVEL=2.0` | 目标速度，单位 rad/s | -30.0 ~ 30.0 |
| `DMKP=2.0` | Kp | 0.0 ~ 500.0 |
| `DMKD=1.0` | Kd | 0.0 ~ 5.0 |
| `DMTOR=0.0` | 前馈力矩，单位 Nm | -10.0 ~ 10.0 |

### 6.4 位置速度模式参数

| 命令 | 含义 | 范围 |
|---|---|---|
| `DMPOS=3.14` | 目标位置，单位 rad | -12.5 ~ 12.5 |
| `DMVEL=2.0` | 目标最大速度，单位 rad/s | -30.0 ~ 30.0 |

位置速度模式下会忽略 `DMKP`、`DMKD`、`DMTOR`。

## 7. DM 电机调试流程

### 7.1 MIT 模式：速度控制测试

```text
DMID=1
DMMODE=1
DMPOS=0
DMVEL=2
DMKP=0
DMKD=1
DMTOR=0
DMEN
```

停止：

```text
DMOFF
```

### 7.2 位置速度模式：转到目标位置

```text
DMID=1
DMMODE=2
DMPOS=3.14
DMVEL=2.0
DMEN
```

### 7.3 保存零点

```text
DMZERO
```

### 7.4 查看状态

VOFA+ 通道 13~18 显示：

- 实际位置
- 实际速度
- 实际力矩
- 状态码
- MOS 温度
- 电机线圈温度

## 8. DM 状态码

| 状态码 | 含义 |
|---|---|
| 0x00 | 失能 |
| 0x01 | 使能 |
| 0x08 | 过压 |
| 0x09 | 欠压 |
| 0x0A | 过流 |
| 0x0B | MOS 过温 |
| 0x0C | 电机线圈过温 |
| 0x0D | 通信丢失 |
| 0x0E | 过载 |

---

## 9. 注意事项

1. DM 电机默认不会自动使能，必须发送 `DMEN` 才会开始发送控制帧。
2. `DMPOS`、`DMVEL` 等参数会先保存，只有 `DMEN` 后才会持续下发。
3. 调试过程中请不要同时移动底盘和 DM 电机，避免相互影响。
4. 调节 DM 电机时建议先保持 `DMOFF`，确认参数后再使能。
5. `P_MAX / V_MAX / T_MAX` 必须与达妙调试工具中的电机参数一致。
6. 若 DM 电机出现 `0x0D` 通信丢失，请检查 CAN1 线缆、电机供电和电机 ID。
7. 急停时发送：
   ```text
   DMOFF
   ```
8. 底盘急停时发送：
   ```text
   STOP
   ```
