基础界面沿用原命令与24通道遥测；后续加入的电机ACC/DEC读写需要更新STM32固件，

## 模式与参数

下拉选择只切换界面。先连接 STM32，点击失能并等待状态码为 0，
点击“应用所选模式”，等待至少 300ms，再点击使能。
模式请求只表示已入队；现有固件没有电机模式寄存器回读，因此界面不显示“模式已确认”。

- MIT 页：目标位置、目标速度、Kp、Kd、前馈力矩，保留各行单独发送。
  应用 MIT 模式时将 Kp/Kd/前馈力矩清零，需要重新设置合适的参数。
- 位置速度页：目标位置和正的速度上限。发送 `DMVEL` 再发送 `DMPOS`；
  位置决定旋转方向，速度参数不是要求电机持续旋转的目标速度。
  位置模式的使能按钮先将速度置零、位置设为实际位置，避免复用上一次目标。
- 电机内部执行位置环、速度环、电流环。MIT 的 `DMKP/DMKD/DMTOR` 不参与模式 2，
  不能拿它们代替内部 PID。位置/速度 PI、电流带宽仍在达妙工具设置；
  驱动ACC/DEC已通过新增接口在Qt整定，不把上位机参考加速度理解为驱动寄存器。

## 精细调整

界面以回转轴角度 °、速度 °/s 显示和编辑，线序仍为 rad、rad/s。
“额外传动比”是 DM 输出轴转数 / 塔吊回转轴转数，默认 1；
不重复乘电机内置减速器的减速比。尚未增加传动方向反转配置。

已有固件钳位位置 ±12.5rad、速度 ±30rad/s，本次不扩大范围。
目标和实际位置都必须在配置的回转软限位中；默认软限位 ±180°，
只作为首次调试起点，必须根据实车的机械限位、线束和传动标定。
软限位由上位机判断，不是电机固件内的独立限位保护。

可调项目：0.001° 输入分辨率、点动步长、速度上限、参考加速度、
角度到位误差、停稳速度、连续停稳时间、曲线结束后的超时。
默认速度 15°/s、参考加速度 30°/s²、到位误差 0.5°、停稳速度 1°/s、
停稳 0.3s、曲线后超时 10s。这些是初始调试值，不是实车整定结果。
输入分辨率也不代表电机反馈精度或实车定位精度。

五次曲线每 50ms 更新一个参考位置，起止参考速度和参考加速度为零。
曲线时长同时满足配置的参考速度和参考加速度上限。
`DMVEL` 只在动作开始时设置正的最大速度，后续更新 `DMPOS`；
待发参考位置只保留最新值，避免串口变慢后堆积过时轨迹。
取消曲线选项时直接发送最终目标，速度上限仍生效，内部运动特性由驱动决定。
这不是实时运动控制器：Qt 定时和实际电机跟踪都可能有误差。

“到位”需曲线结束后，来自动作开始之后的新遥测位置与速度连续满足条件。
同一个采样不能重复累计停稳时间。遥测陈旧超过 350ms、GUI 调度中断超过 350ms、
超时、失能、故障、ID 不一致或实际越过软限位，会取消流程并请求 `DMOFF`。
STOP/DMOFF/DMSTOP 立即撤销流程；执行期间外部 DM 目标/模式/零点/使能命令
会先终止流程并请求失能，原命令需等停稳后重新执行。

现有 STM32 遥测携带的是缓存的 DM 反馈，没有独立 CAN 反馈时间戳。
因此本次的遥测新鲜度检查只能证明 STM32 上行仍更新，不能证明每一帧都有新的电机 CAN 回包；
到位显示也不能代替夹爪、升降和物料存在传感器。

## 四个示教位置与搬运流程

示教位置默认均未设置：待抓取位、车上载盘 1/2/3 号位。
手动调整到目标，停稳后“记录实际”；或输入测定的角度并“保存输入”。
保存本身不产生运动，“前往”使用已保存值。
保存角度和调试设置到上位机目录 `dm_positions.json`，原子写入，
没有写 STM32 Flash，也没有存储夹爪/升降/伸缩位置。
首次加载、切换连接、修改传动比、请求 DMZERO/DMID 后，
必须重新确认电机 ID、零点、传动比与示教一致。不同电机 ID 的示教不能直接使用。
断电重启或通过其他工具改变零点后，也必须重新核对或重新示教。

1. 示教并保存待抓取位和实际要使用的载盘位，确认零点一致。
2. 前往待抓取位并停稳，由操作者抓取物料并抬升至允许回转的高度。
3. 选择载盘位，点击“确认已抓稳并抬升 → 转到载盘”。
4. 反馈到位停稳后，返回按钮才可用；操作者降下、释放物料并再次抬升。
5. 点击“确认已放妥并抬升 → 返回待抓取位”，反馈到位后可抓下一件。

本次只发送 DM 回转命令，没有已验证的夹爪开合映射及升降到位反馈，
没有自动发送 S28/S35 或模拟释放物料。正式比赛的自动调度需另行接入实际执行器和传感器。

## 比赛依据

用户指定的 `附件1-1-第九届湖南省大学生工创大赛工程实践赛道命题与运行.pdf`
为工程实践赛道文件，涉及能源车辆，不是智能搬运。
本次参考同目录 `附件2-1-第九届湖南省大学生工创大赛智能+工程创新赛道命题与运行.pdf`
第 7–8 页：每次取一个物料，须先放至车上，再取下一个；不得一直夹持物料行驶到下一功能区。
车内载盘 1/2/3 号位属于本车机构示教，不等于比赛颜色编号或场地摆放圈编号。
原料盘的三个物料间隔 120° 属于比赛转盘布局，不能据此推定塔吊的载盘角度。
比赛文件要求运行期间不得操作笔记本或遥控器，本页供赛前调试和示教。
