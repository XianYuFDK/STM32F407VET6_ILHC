# 地图青线与跳动修复（2026-10-05）

用户截图：实机点击路径CANCELLED/4点/1076mm，界面场地坐标0cm、2cm、0.5°，青色轨迹突然延伸到场外且整张地图跳动。

已复现串口解析缺陷：二进制JustFloat固定100字节遥测之间插入TSTAT或参数回读行后，旧解析器丢失同步，重新搜索帧尾。某个payload通道的+inf与帧尾四字节相同；在前面有文字时，这个内部标记被误作真正帧尾，把ASCII与半帧数据当作24通道遥测。原始测试中真实OPS恒为(0,2,0.5)，旧解析器交付(13.2703,0.0000106,0.000000149)，后续还交付(0,0,0)。这会污染实时坐标、历史青线和运行车体检查。

修复：仅在帧边界先消费完整可打印ASCII应答行，分片文字等待换行，保持二进制固定100字节同步；TSTAT/CCAPS/参数回读仍由原文本通道完整交付。合法payload里的+inf仍可正常显示，不靠删除非有限机械通道判断遥测。地图历史绘图遇到非有限/极端坐标或500mm跨点跳变时断开连线，原始环形缓存及录像值不改，运行停车门不变。

这是与截图症状一致的可复现缺陷；截图没有原始串口字节，不能据此断言当次所有越界取消都是假遥测。实际地图、车体越界仍会停车。

本轮只改上位机，重启上位机加载修复即可；没有改动/编译/烧录STM32，没有连接或驱动实车。专项覆盖帧间TSTAT/GET/ACK、启动CCAPS、1/3/17字节分片与整包、重复文字、payload内+inf和地图异常点断线。122项相关Qt/串口/实机批次/专项回归通过（进程退出0），日志：Docs/map_jitter_regression_20261005.log。
