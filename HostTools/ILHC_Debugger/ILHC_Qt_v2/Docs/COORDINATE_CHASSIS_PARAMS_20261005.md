# 新PC坐标控制使用底盘调参

用户要求新坐标直接使用`chassis_move`的参数。新PC点击路径、完整比赛TRAVEL的预演和执行均读取模拟器已生效的七项底盘参数，来源就是“底盘调参”页的发送/回读链路；不再使用独立的2.3/2.3/9和250/120限速副本。STM32的现有单点GOTO及整批轨迹协议未修改。

## 使用

重启上位机，开启“模拟”，在“底盘调参”页编辑并发送参数，确认右侧回读。回到地图重新规划点击路径或启动完整比赛模拟即可。输入编辑本身不发送，不改变当前有效参数。

发送底盘参数会立即取消旧PC路径、正在计算的计划及整场比赛模拟；旧预演不能继续执行。新规划先按原队列顺序处理已发送的参数，再抓取参数快照。不抢先跳过STOP/失能等排队命令。新模式的计划台账列出七项实际使用值，摘要显示底盘增益和XVMAX，JSON保存参数来源和快照。

实机单点GOTO仍用此页，实机整批路径仍用“轨迹调参”页；本次没有把PC新关键坐标协议接入STM32。

## 七项参数的意义

| 参数 | 新坐标控制作用 | 默认 |
| --- | --- | --- |
| KPX | 实际航向转换后的车体左右误差P增益 | 2.3 |
| KPY | 实际航向转换后的车体前后误差P增益 | 2.3 |
| KPZ | 最短航向误差的P增益，输出旋转轮缘线速度量 | 9 |
| XVMAX | 左右/前后控制量分别限幅，单位mm/s | 1600 |
| ZVMAX | 旋转轮缘线速度量限幅，单位mm/s | 750 |
| XVMIN | 平移P输出绝对值大于5时加同号补偿，再限幅 | 5 |
| ZVMIN | 航向P输出绝对值大于5时加同号补偿，再限幅 | 5 |

与固件`numerical_limit(...,5.0f)`一致：绝对值不大于5时保留P输出，并非强制置零。系数/速度上限允许0，但没有位置或航向进展的路线明确拒绝，不能挂起规划或强行通过。

内部数学车体轴的第一轴是前、第二轴是右；因此KPY乘前向误差，KPX乘右向误差（对应左右轴），避免把截图的KPX/KPY用反。

Z参数的线速度量通过固件同值270mm旋转臂长换为角速度：`omega_deg_s = degrees(z_command / 270)`。默认ZVMAX=750对应约159.15°/s的模型上限，不是750°/s；KPZ=9也不是9°/s每度误差。四轮混合后保留同比归一化，按0.238 RPM/(mm/s)换算检查3000RPM单轮上限。

独立的250mm/s、120°/s帽已从新坐标控制移除。XVMAX是每车体轴的限幅，不是合速度限幅；斜行合速度可以高于它。大于30°航向纠偏时仍保留规划器的20%平移减速，最后STOP仍要求位置、航向和停稳。比赛出入库的明确MANEUVER及旧几何段兼容模式保留原模型限速，并未冒充整套固件。

进入末点0.5mm/0.3°门后，平移停止，剩余小角度通过实际限速积分完成并重新扫掠检查，再满足10帧停稳。ZVMAX仍限制角速度，KPZ=0不增加隐藏航向控制。此处理修复两障碍返程曾残留约1e-12°导致贴边入库严格几何检查失败的问题，不取整真实起点、减少裕量或静默修改显示姿态。

PC仍是理想运动模型，没有复制固件四轮整数截断、速度斜坡、电机迟滞、轮胎打滑等全部物理行为。参数、P控制轴含义和限幅量相同，不代表仿真时间或实际响应完全相同。

## 参数一致性和碰撞保护

`Simulator.chassis_parameters()`以运动锁保护参数快照，默认来自公共`CHASSIS_PARAMS`表。规划参数进入同一控制器的完整矩形预演和扫掠检查。接受执行前、预演期间、接受检查结束和运行每帧再次核对当前参数；参数变化取消控制，旧路径不能被重新挂回。

完整比赛保存一份`chassis_control`快照，所有TRAVEL使用同一组。站点作业与出入库期间也保留快照有效性门，调参不会在下一路段静默换另一组值。界面计划签名包含参数值；外部调用更改参数也会令旧计划失效。

坐标JSON现在是`PC_COORDINATE_PROGRAM`/schema2，`control_source=CHASSIS_MOVE`，control为七个小写参数名加`turn_lead_mm`。schema1的旧独立速度程序明确要求重新规划，防止错误解释角速度单位。

整车矩形、安全裕量、drivable、障碍、相邻姿态扫掠、起点匹配、STOP、75mm偏差和无进展等门没有放宽。低速度/不同增益仍重新选择安全转角策略；无法通过时返回明确fallback。

较高底盘速度会改变过弯响应，因此候选增加5mm通过范围和200mm提前转头组合。先搜索原切线/当前车头图，无安全结果时再检查正交车头下的短侧移连接，最后细化障碍车道；各轮独立预算，防止新增分支挤掉原图有效候选。两障碍区2返程由暂存位侧移到外侧通道绕行，避免沿窄角点切入黄区。各姿态的几何缓存独立，最终仍由实际控制器扫掠决定是否放行。

## 验证

新增七项参数影响、KPX/KPY轴区分、Z限幅/单位转换、最小补偿、去除250帽、陈旧参数拒绝、接受时变参取消、零限速无进展，以及非默认参数整场比赛测试。真实Qt增加发送按钮→回读→新参数规划→执行完成，以及运行中发送、整场比赛发送时立即取消的测试。

最终6组核心自检、276项无GUI与分模块178项Qt（90/9/28/22/19/10）全部通过，各测试进程退出0。Qt地图与调参测试另验证了真实按钮和回读；本轮未用模拟通过代替实车验证。
