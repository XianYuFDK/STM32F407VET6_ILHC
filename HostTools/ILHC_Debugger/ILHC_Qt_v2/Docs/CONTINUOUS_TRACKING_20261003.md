# PC模拟器连续轨迹跟踪（2026-10-03）

最新跟踪修订保留100mm前视X/Y/unwrap Yaw，运动控制加入当前实际投影处的几何增量、切线/曲率前馈和投影误差反馈，前视窗口提前按小圆弧限速；避免直接朝前视点走弦导致切内和提前旋转。进度仍由实际位置决定、中间样本不停车，终点停稳及全部碰撞门禁保留。详见[比赛静态避障优化](AVOIDANCE_OPTIMIZATION_20261003.md)。

已将“仿真行驶”改为连续跟踪整条安全Trajectory。车辆通过所有中间采样点，只有终点进入STOP与停稳判定。整条轨迹只接受一次，使用一个epoch和goal_id；没有逐点GOTO命令或航点到位等待。

## 控制与坐标

- 新增`trajectory_tracking.py`，按实际FIELD_MM位置投影到原始LINE/ARC连续几何，累计进度`s_mm`只能增加。
- 搜索范围为上次进度到“上次进度+实际位移+20mm”，同距选择较早位置，避免U形、闭环和自交路线跳到后面的分支。参考点或调用次数不能自行推动进度。
- 每步参考弧长为`min(progress+100mm, total_length)`。位置和Yaw由真实直线/圆弧几何插值，圆弧使用真实弧长、切线Yaw及unwrap，不用圆弧采样点之间的弦代替圆弧。
- 模拟器以50Hz、20ms积分步长根据移动参考X/Y/Yaw更新实际车体位置和航向；Qt的20ms定时器显示参考与监督会话。
- PC运动学演示限速250mm/s，角速度上限120°/s，圆弧段额外按`0.8*R*角速度上限`限制速度。最终100mm内参考锁定终点并减速；中间点没有停稳条件。
- 位置采用FIELD_MM：`field=(2250-layout_y, 2250-layout_x)`；FIELD航向=`-90-layout_yaw`。含旋转/平移标定时仍使用统一FIELD↔OPS变换。

终点满足实际位置误差<1mm、航向误差<1°、模拟平移速度≤1mm/s、角速度≤1°/s，并连续10个新积分帧（200ms），才标记`COMPLETE`。GUI另外核对epoch、goal_id、completed_id、新鲜定位和实际终点姿态；旧dev[]、重复界面轮询和伪造完成ID不能推进或判定完成。

## 安全和取消

接受轨迹前，按当前场景重新做整条Trajectory矩形车体复检。实际起点须在轨迹起点5mm内，实际航向须在首段切线5°内；航向未对齐会明确拒绝，需要先调整车头再重新规划。不会执行未检查的起点原地旋转。仍含TURN、硬直角或失败fallback的结果不能连续跟踪。

运行中每一步都检查实际车体的完整矩形+安全裕量，并对线性中心位移与旋转检查连续包络：相邻姿态凸包加车体顶点转动弦高外扩。整个实际扫掠必须包含在drivable白名单内，且不与固定、模拟或动态障碍接触。控制器存在转弯切内偏差，真实轨迹偏离规划线时由该检查决定是否可继续；碰撞或偏离75mm以上立即取消。

STOP、清路径、重新规划、地图版本/几何改变会同步撤销模拟器epoch、跟踪器、参考点、速度及待处理运动命令。地图顶层赋值/更新/删除/整体替换在写入新数据前取消；原地修改嵌套列表也由每个积分步的快照一致性检查拒绝。动态障碍的公开更新接口先取消再更新快照。

接受阶段的昂贵全轨迹检查在运动锁之外，STOP可直接抢占。正式接受前与每次位置/航向提交前再次检查会话、地图和控制权，防止取消期间旧检查结果恢复运动。所有运动状态提交与取消使用同一个锁。ZERO、OPSOFFSET、失能、手动接管、硬件链路接管和标定变化也撤销跟踪。

NaN/Inf姿态、定位跳变>50mm、航向跳变>15°、检查异常、持续3秒无进展及总超时会进入`FAULT`并停止。没有串口导航调用，未连接STM32，未修改固件或协议。旧手动/GOTO调试仍保留，连续跟踪使用独立PC接口。

## 地图和使用

地图同时显示黄色虚线Manhattan骨架、绿色平滑连续轨迹及方向箭头、紫色当前参考点与参考航向、蓝色实际车辆轨迹。清路径清除规划和参考，保留实际历史轨迹；完成后保留骨架与平滑轨迹便于对照，参考点消失。

启动`python main.py --simulate`，在“比赛地图”规划，再点“仿真行驶”。目标航向选择进入原规划台账，只有通过连续几何与矩形复检的结果可执行。起始航向须对齐首段切线；重新运行需要重新规划。
