# 出库后停车：电机整数转速截断修复

历史v2.1.5验证记录。后续用户要求取消3秒无进展自动終止，并修复定位噪声停稳误判，现行行为见[STATION_STOP_20261005.md](STATION_STOP_20261005.md)。这里的旧/新模型对比脚本显式恢复旧3秒故障策略，仅作整数RPM缺陷的历史对比。

截图在约210mm进度、OPS约(150,148)mm处停止，STM32报告FAULT14。关键坐标的无进展时间是3秒；此前上位机共用旧轨迹的错误说明，错误显示为5秒。此处对应出库后的staging停车点，地图碰撞开关无法绕过STM32无进展保护。

离线复现串起真实`trajectory_buffer.c`、`chassis_move_reference`、世界速度转换、麦轮混控、整数RPM和ZDT下发；仅电机通信与实际运动用桩及逆运动学替代。旧输出永久截去不足1RPM的部分：到(149.118,149.118)mm时仍请求每轴约2.03mm/s，但四轮整数转速全为0。停车误差约1.248mm，超过1mm完成门限，随后FAULT14，进度210.9mm。截图没有当次原始数据流，因此复现证明了与现象吻合的固件缺陷，不能反推当次每个轮速。

修复后的世界速度输出先用浮点轮速同比限幅，再保留每轮不足1RPM的余量，后续20ms周期累计输出整数RPM。低速平均输出跟随原请求，不修改KPX/KPY/KPZ/XVMAX/ZVMAX/XVMIN/ZVMIN。零轮速、反向、STOP、清目标、失能及手动速度接管均清掉相应余量；仍禁止超出3000RPM。PC坐标预演和模拟同步使用整数RPM模型，并按逆运动学积分实际输出，避免再次用浮点理想速度掩盖截断。

| 同一三点出库测试 | 旧整数截断 | 修复后 |
|---|---|---|
| 结果 | FAULT14，停在首个停车点前 | DONE，经过首个停车点到下一点 |
| 结束坐标/mm | 149.118,149.118 | 150.000,299.580 |
| 结束进度/mm | 210.9 | 362.1 |
| 故障码 | 14 | 0 |

另一个单轴用例从(150,0)mm到(150,150)mm再到(150,300)mm：旧代码停在(150,148.235)mm，与截图显示的(15.0,14.8)cm相近，同样FAULT14；修复后DONE，终点(150,299.580)mm。
