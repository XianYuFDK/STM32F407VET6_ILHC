# 连续轨迹调参（2026-10-04）

新增左侧“轨迹调参”页面，比赛地图实机按钮旁也提供“轨迹速度调参”入口。
参数适用于STM32完整比赛整批路径和点击路径，GOTO继续使用原底盘参数。

## 参数

| 命令 | 含义 | 默认值 | 范围 |
| --- | --- | --- | --- |
| TVMAX | 平移速度上限，mm/s | 500 | 20～1000 |
| TKPX | OPS世界X位置纠偏，1/s | 6 | 0.1～30 |
| TKPY | OPS世界Y位置纠偏，1/s | 6 | 0.1～30 |
| TKPZ | 航向纠偏，1/s | 6 | 0.1～30 |
| TWMAX | 移动时角速度上限，°/s | 120 | 5～180 |
| TRWMAX | 原地转头速度上限，°/s | 60 | 5～120 |
| TRACC | 原地转头加速度，°/s² | 180 | 10～720 |
| THOLD | 转头时车心保持平移限速，mm/s | 60 | 5～150 |
| TLOOK | 前视距离，mm | 100 | 20～300 |
| TACC | 路径前馈加速度，mm/s² | 600 | 50～3000 |
| TDEC | 规划制动减速度，mm/s² | 1000 | 100～4000 |
| TVARC | 圆弧平移速度上限，mm/s | 150 | 20～500 |

平移包含路径前馈和位置纠偏，再按TVMAX进行矢量限幅。原地转头车心保持速度同时受THOLD和TVMAX限制，原地转头角速度同时受TRWMAX和TWMAX限制。圆弧航向变化率和站点接近距离仍自动降低速度。
TKPZ同样用于起点STOP、移动、原地转头的航向纠偏；TKPX/TKPY也用于转头车心保持。
TLOOK改变参考与减速预判范围，前馈仍沿当前路径几何增量计算，不以直接追前视弦替代路径跟踪。

## 使用

1. 使用EIDE编译出的配套固件，重新打开新版上位机。
2. 连接STM32，进入“轨迹调参”，点击“回读全部”。右侧回读是板上实际值。
3. 在轨迹停止时修改输入，单行“发送”或“发送全部”。仅编辑输入不发送。
4. 每150ms至多发送一项，发出设置后GET回读，收到该项回读再继续下一项。
5. 完成设置后启动点击路径或实机比赛。轨迹准备、上传、运行期间PC拒绝修改；MCU在RECEIVING/VERIFYING/READY/RUNNING/WAITING均拒绝修改。

未确认、回读不符、超过3秒或固件报ERR时，不显示“已生效”，中止尚未发送的后续项。旧固件GET返回未知参数时提示需要配套版本。串口会话重置清空旧回读和待发设置。

“恢复默认输入”和“加载JSON”只更新输入框，不发送命令。“保存JSON”保存电脑上的输入配置；12项参数为RAM参数，重启恢复默认。原PARAMSAVE的Flash记录保持16字段，无轨迹参数持久化。

PC模拟使用自身的轨迹模型，此页明确用于实机；模拟模式拒绝这12项下发，避免参数显示改变而模拟运动没有改变。

原有整批上传、STOP/取消、站点真实停稳200ms、定位新鲜度、偏差门限及碰撞检查均保留。本次增加调参接口，不宣称已经解决实车圆弧跟踪偏差。
