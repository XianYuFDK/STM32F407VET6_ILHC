# PC坐标路径小圈和长横移修复

用户截图中的问题在默认比赛图复现：原料到粗加工选择COORDINATE_FIXED，保持横向车头横移约1598mm；粗加工到暂存选择(1200,400)→(300,400)→(300,300)→(400,300)→(400,1200)，三个短折返形成小圈和连续转头。此前的安全扫掠通过只证明不碰撞，没有证明路线合理。

原因是默认XVMAX1600下，大角度纠偏仍按20%平移，最高320mm/s，直接纵向过弯候选先进入窄道导致扫掠失败；原料站靠近圆盘，立即转头也可能扫到圆盘，随后规划选中长横移或绕小圈的安全候选。

本次只修改PC坐标控制及规划：

- 大于30°的航向纠偏阶段平移系数从20%降为5%，仍同时平移和转头，七项底盘参数继续生效。
- 添加通过范围5mm、提前转头10mm的候选，用于角点附近完成转向。
- 添加80/120mm离站过渡坐标候选：短段保留进入时车头，接近过渡坐标时转向后续纵向车道。点在原直线上，不生成圆弧，也不要求途中停稳。
- 所有候选按实际预演统计连续横移；超过500mm拒绝继续选其他车头/路线，不自动采用长横移兜底。结果记录实际max_strafe_run_mm及motion_metrics。
- 原有矩形、安全裕量、合法行驶区、障碍、相邻姿态扫掠、STOP和变参取消保护继续执行。

默认区1第一批原料→粗加工现为(1200,2030)→(1200,1950)→(1200,400)，连续近侧向移动约38mm；第二批已沿纵向，可直接行驶。粗加工→暂存改用(1200,400)→(1200,1200)→(400,1200)，消除角落小圈。

默认两启停区回归增加：每段实际连续横移小于100mm、累计航向变化不超过181°、骨架各轴无折返；完整比赛及碰撞扫掠仍独立执行。35项坐标/点击逻辑专项通过，日志coordinate_turn_targeted_final_20261005.log。地图/界面与8轮场景最终结果见coordinate_turn_qt_*_final_20261005.log、coordinate_turn_simulation_final_20261005.log及coordinate_turn_results_20261005.json。
