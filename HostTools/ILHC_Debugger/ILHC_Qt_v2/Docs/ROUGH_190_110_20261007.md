# 粗加工停车点更新

按用户要求，两默认地图的粗加工停车点从 (200,105) cm 改为 (190,110) cm，LAYOUT 对应 (1150,350) mm。比赛站点、关联车道节点及标定元数据同步更新，作业航向仍为界面 180°。原料 (10,105)、暂存 (110,190) cm 及实际出发 OPS 零点保持。

设备和固定禁区未移动，车体尺寸和碰撞裕量未改。新点在现有模型中到粗加工设备边缘净空为 140 mm；历史约 40 mm 间隙记录针对此前停车点，不作为新点实测结果。粗加工至暂存经 LAYOUT (350,350) 走外侧，保持沿车尾离站。

检查覆盖两默认地图的坐标/航向/碰撞、Qt快捷目标、OPS置零不改站点、暂存离站残差。Qt测试最初加载历史地图而报告旧坐标，已改为测试实际默认地图并复跑19项通过，历史文件保留。整场回放及缓存证据见 rough_190_110_release_20261007.json 和 rough_190_110_manifest_20261007.json。
