# 点击路径STM32接入与模拟直接回库

连接STM32、底盘使能且OPS有效后，勾选“点击地图 = 规划路径”。点击空闲目标或快速区域按钮，先停止旧轨迹，以实际位姿生成避障路径，再自动完成整批预检和上传。所有点接收、CRC及结构校验通过后只发送一次TRUN。STM32本地连续跟踪，中间20mm采样点不停稳，不逐航点发送GOTO。程序接口plan_to仍可只预览，再使用“执行规划路径”按钮提交整批。

按2026-10-04用户要求，直接采用当前地图进行实机跑图，不再要求geometry_verified=true。此字段保留原值作为地图元数据；不修改地图几何。点击路径不要求完整比赛competition配置，整轮跑图仍需competition站点配置。OPS坐标与地图的对应关系仍按界面设置，起点/车头在规划或预检后变化超过5mm/3°会拒绝，STM32启动时再次检查。未连接时仅离线预览，PC模拟点击仍先规划后执行。

连续直线/圆弧优先，上传按20mm/3°细采样；按实际起始车头增加必要的出发转头，按目标航向选择增加最终转头。所有转头、量化后的真实矩形及相邻点扫掠重新检查。无法连续平滑时采用已校验台账的显式停靠/转头，界面显示“停转回退”，JSON记录STOP_TURN_FALLBACK及原因，绝不强行平滑。不安全的回退也拒绝上传。STOP、重规划、地图/障碍/标定改变、失联、失能均取消批次并清除排队点/启动命令，不能恢复旧轨迹。

删除“障碍比赛场景”固定四障碍预设按钮和处理函数；手动放障碍、随机补齐、清除障碍保留。比赛启动沿用当前模拟障碍，不追加预设、不清空已有障碍。地图原有固定场地结构仍参加碰撞检查。DEMO_OBSTACLES仅保留作离线回归夹具。

2026-10-04按用户最终明确的条件：只有手动STOP或保护停止后，下一次“回启停区”才能直接从当前位置返回，跳过规划/碰撞门禁，PC模拟与实机均支持。普通清路径、正常完成或正常回库不享有此例外，仍走避障规划；取消“点击规划”开关也不放开回库限制。直接回库保留所选启停区、OPS映射和默认车头0°，不瞬移、不ZERO、不改障碍、不恢复旧比赛。模拟器在锁内处理更早的STOP/失能再创建目标；实机先STOP完整发送并等待新鲜OPS连续停稳200ms，之后只发送一次GOTO，无需上传轨迹点。新的STOP、失能、定位/链路异常、重规划或地图变化取消回库。直接回库一旦发起即消耗例外状态，开始新的运动也清除例外。详见STOP_RETURN_20261004.md。
