# 上位机经STM32整定DM内置梯形加减速

此功能同时修改Qt和STM32固件；重启上位机并更新STM32固件后使用。
STM32 USART1仍为115200/8N1，CAN2仍使用原配置；不直接连接USB2CAN的COM5。
内置位置速度模式标准帧仍是0x100+电机ID，默认0x103。

## 操作

1. 连接STM32，切到DM页位置速度界面，失能并等待反馈。
2. 应用位置速度模式；等待切换，关闭“上位机五次曲线”。新安装默认关闭，旧JSON可能保留已保存选择。
3. 点击“读取ACC/DEC”，读取当前驱动实际参数。读取按钮不会使能或移动。
4. 修改加速度、减速度大小，点击“写入并回读”；确认电机回读成功再继续。
5. 使能先保持当前角度、速度零；设置较小目标角度和速度上限，执行位置目标。
6. 示教抓取位和载盘1/2/3位，可按原人工确认流程抓稳抬升→转载盘→放妥抬升→返回。

驱动加速度ACC为正，减速度DEC为负；界面输入减速度大小，发出时取负。
单位Krad/s²（1000rad/s²），使用驱动原始数值，不转成回转轴°/s²，不乘额外传动比。
初始输入2不代表已经写入，也不是机构推荐值；应先读取实物再整定。
读写范围1e-6..1000只是本接口限制。较小加减速可能显著延长运动时间，必要时调整高级超时设置。

本轮仅更新电机RAM；掉电恢复电机原保存参数，每次连接/修改ID或模式后需重新读取。
“保存设置”仍保存PC参考曲线/软限位/示教JSON，不保存电机ACC/DEC或写电机Flash。

## 两种运动方式

| 项目 | 内置梯形（五次曲线关闭） | 上位机五次曲线开启 |
|---|---|---|
| 位置目标 | 直接提交最终目标 | Qt每50ms产生参考位置 |
| 加减速来源 | 电机RID4/RID5 | PC参考加速度°/s²控制参考曲线 |
| 速度 | DMVEL设置最大绝对速度 | 同样设置DMVEL速度上限 |
| 到位 | 实际位置/速度连续停稳 | 曲线结束后实际位置/速度连续停稳 |

电机内置梯形是速度的加速→匀速→减速，短距离可能为三角形速度过程。
ACC/DEC不替代内部PID；MIT Kp/Kd也不参与电机位置速度环。
PC模拟器标注“模拟回读”，只演示参数接口与操作门禁；运动沿用原模型，不能证明真实梯形效果。

## 链路与失败处理

新增DMREAD=seq、DMACCDEC=seq,acc,dec。MCU异步CAN读写，任务周期推进，中断只缓存应答。
先写ACC、DEC，再分别发送独立读取，核对实际数值；写回显不当作读取成功。
FW单步400ms超时、结束500ms隔离窗口，UI等待上限3s。
seq和ID匹配才更新界面，过期或其他会话响应不会确认新请求。
必须有300ms内真实CAN失能反馈；无反馈、MCU活动或事务忙都会拒绝。
STOP/DMOFF/主机失联取消；超时/失败可能已经部分写入，重新失能读取后检查。
24通道100字节遥测不变，结果通过USART文字队列回传。

电机CAN寄存器协议没有事务序号，只能按ID/RID及隔离窗口匹配，不能完全区分无限迟到的同RID响应。
调参时不要使用第二个CAN主控并行读写。模式切换沿用原请求，无模式寄存器确认。
位置到位仍使用原遥测缓存，未新增独立CAN反馈时间戳；不能把上行每帧更新当成每帧电机反馈。
