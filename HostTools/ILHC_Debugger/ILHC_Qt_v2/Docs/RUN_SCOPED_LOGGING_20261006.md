# 自动日志随运行开始、结束

用户要求实机跑完或手动STOP自动结束日志，模拟一样。当前v2.1.18上位机已修改，不涉及固件与运动控制，重启上位机生效。

## 行为

- 连接实机、开启模拟只绑定记录源；待机不创建日志文件、不记录持续遥测。
- 批次/比赛/路径或手动运动开始时建立独立REAL/SIM目录，保留原始事件、遥测、计划及参数快照。
- 比赛/路径完成、取消、手动STOP、手动零速度或断连后停止接收新日志；后台排空已有记录，写入RUN_END/result.json和SESSION_END后关闭文件。
- 下一次运行自动另建目录，旧文件不会接着增长。界面提示待机、正在记录、已结束及路径。
- 批次上传前的内部STOP不结束批次日志；波形“暂停”仍继续记录进行中的运行。
- 原顶部“记录”按钮的手动CSV机制独立。没有可靠完成回读的直接调试命令不推断成功，仍在明确STOP/取消/断连时结束；直接回库沿用已有到位停稳判断结束。

每次结束不等待磁盘，不延迟串口和STOP发送；已经排队的数据可能在结束后短暂写入，写完即关闭，不继续记录待机数据。即使遥测队列满，结束状态也通过独立终止队列保存；磁盘本身失败仍会显示错误。

旧圆弧模拟计划中的ArcSegment对象现在通过已有as_dict转换保存，避免写计划时报错而遗漏结果文件。此修复不改变圆弧或绕麦轮的算法。
