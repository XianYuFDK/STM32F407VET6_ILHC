# 车头0°朝+Y修订

用户明确要求车头默认朝场地+Y为0°。此前把这句话按地图几何角+X为0°理解，
把启停区标定旋转设为90°，实际车头也转到了+X，这是上一轮修复的理解错误。

现在界面车头约定为：0°上(+Y)、90°左(+X)、180°下(-Y)、270°右(-X)。
两启停区普通模拟、OPS校准、比赛初始化均默认朝+Y；校准旋转0°，OPS相对车头0°。
目标选择、回启停区航向、车辆图标、跟踪参考显示使用这一约定。

旧白色三角形使用前沿两个角作底边，尖端在车心；现在尖端在前沿中点，底边在车心左右，
可以直接按三角形尖端识别车头。车体矩形尺寸和碰撞外形保持真实280×260mm。

计算用Trajectory角度保持+X=0°、+Y=90°的几何定义，避免改变采样、圆弧、碰撞和导出接口。
界面车头角=`(90 - 几何角) % 360`；OPS到界面=`(ops_yaw + map_theta) % 360`。
界面目标到OPS=`(界面目标 - map_theta) % 360`。
最终STOP必须将实际角换成几何角比较Trajectory，不能直接混用两种零点。

两区三种障碍场景六轮完成12抓/12放及同色双层码垛，逐帧实际矩形和连续扫掠均安全；
结果见`yaw_y_zero_results_20261003.json`。新的实际初始方向改变了矩形在车道中的横纵占用，
因此不能继续引用旧朝X默认版本的所有计时或“六轮全程不转向”结论。
