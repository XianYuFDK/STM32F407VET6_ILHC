## 3. 贴边裕量不足：实际轨迹侵入规划膨胀区

以原地图和原车体重放实际OPS位姿：63帧不满足10mm矩形膨胀检查，集中在RUN_START后34.37–34.57、38.31–38.49、83.55–84.13、91.09–91.31秒；68个相邻姿态区间也未通过同一保守扫掠检查。

去掉裕量、只检查280×260mm车体时，未发现采样位姿与障碍重叠。采样车体外缘最小欧氏净空约8.15mm。因此证据支持“规划裕量被实际跟踪偏差消耗”，不支持断言实车已经撞上物料区。10mm是沿车体局部轴的矩形膨胀，旋转时不等同于所有方向的欧氏净空10mm。

本轮`runtime_collision_protection=false`，所以没有因这些位姿触发地图取消。固件75mm路径偏差门不等价于地图碰撞检查。日志地图本身尚未经过实测认证，OPS也不是外部定位真值，以上结论均受这两项准确性限制。

## 4. 速度不连贯：普通小通过门与绕轮专用制动混用

本轮普通PASS多数仅5mm；绕轮入口为1mm且航向<1°，出口为2mm且航向<1°。普通点位用位置P控制接近目标，绕轮邻接直线才启用有限距离制动、80mm/s衔接和加速度限制。不同段的速度曲线本来就不同；严格小通过门又会让普通段长时间减速接近点位，接下段后重新加速。

原料、粗加工、暂存、回库等STOP仍需满足位置/航向/请求速度条件和连续200ms姿态稳定窗口。主要站点从首次CCTRL距离<2mm到状态完成约0.66–1.0秒，其中包含继续收敛、稳定窗口和状态采样延迟；未发现本轮再次出现此前那种毫米级反复微动导致的5秒以上额外停靠。两次原料到粗加工分别22.12、21.87秒，模型均16.06秒，是本轮最大的实际与模型耗时差。
