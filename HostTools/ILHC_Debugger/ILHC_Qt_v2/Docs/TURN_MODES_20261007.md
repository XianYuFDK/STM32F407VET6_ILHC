# 三种转弯模式（上位机2.1.21）

比赛地图上方新增“转弯模式”，默认“优先绕轮转向”。适用于关键坐标点击规划、完整比赛模拟和实机整批运行。三个作业坐标及0/180/90°作业朝向、OPS零点保持不变。

|界面名称|标识|行为|
|---|---|---|
|行进中转向|MOVING|关闭指定轮心过弯扩展，优先使用普通点位通过及提前转向；完整扫掠复核后才交付。作业点和回库仍停稳，不承诺所有狭窄角落都不停顿。|
|优先绕轮转向|WHEEL|满足几何与完整回放条件时优先采用指定麦轮轮心过弯；不可行时保留安全普通路线，不能为强制绕轮而放松碰撞检查。|
|到点后转向|STOP_TURN|平移至坐标停稳，再在同一坐标转向并停稳，之后进入下一段。通过重复坐标及STOP标志表达，不使用提前转向或绕轮扩展。|

到点模式采用现有STM32坐标STOP协议，每个中间停车/转向阶段使用200ms整姿态停稳条件；PC模型同步支持中间STOP和同坐标转头。到达最终坐标但尚未完成最后航向时，模型不得提前报告完成。固件本已有中间STOP执行，不新增协议，不需刷固件。

模式存于地图快照turn_mode；更改模式取消原规划及正在运行的规划任务，重新规划后方能执行。固定缓存包含模式在内的地图散列，互不串用。运行metadata、plan和完整比赛输出记录模式，便于将三种运行日志与地面实际归位偏差对应。历史不含字段的地图默认WHEEL。加载保存了模式的地图会同步下拉框。

三种模式用于隔离运动方式与定位误差的关系，不等于已经修复OPS物理闭合偏差。实车比较时使用相同出发位置、朝向及地面基准。未连接串口或自动启动车辆。

验证脚本tests/test_turn_modes.py覆盖实际安全路线差异、量化后STOP/PIVOT标志、中间停稳、缓存隔离及Qt选择/日志元数据。完整回放与缓存清单见turn_modes_release_20261007.json、turn_modes_manifest_20261007.json。旧缓存保留，按新算法散列自然失效。

已通过69项逻辑/Qt/接口测试，以及两地图×三模式×两组控制参数共12次完整回放。另逐组检查实际量化批次：行进模式20点/无轮心，绕轮模式23点/2～3个轮心，到点模式30～32点且全为STOP、只有相同坐标点之间发生航向改变。72条路段缓存文件SHA核对并发布。模拟耗时不作为实车性能保证，Jetson Nano未实测。
