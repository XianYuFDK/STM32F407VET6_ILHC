# 实机轨迹500 mm/s档（2026-10-04）

按用户选择，将STM32整批点击路径和完整比赛的默认直线速度上限从250改为500 mm/s。增加路径前馈加速、未来圆弧与STOP的制动距离预判，以及接近原偏差保护门限时的前馈减速。路径仍在出发前整批上传，途中由STM32根据OPS连续闭环执行。

## 参数与操作

| 参数 | 默认值 | 单位 | 用途 |
| --- | ---: | --- | --- |
| TVMAX | 500 | mm/s | 平移指令矢量速度上限 |
| TVARC | 150 | mm/s | 圆弧段平移指令上限，车头保持不变的圆弧也受限 |
| TACC | 600 | mm/s² | 路径前馈起步加速斜坡 |
| TDEC | 1000 | mm/s² | 规划入弯、到站制动距离所用减速度 |

TKPX/TKPY/TKPZ保持6，TWMAX保持120°/s；原地转头速度60°/s、加速度180°/s²、车心保持60 mm/s、前视100 mm均保留。弯道还受轨迹航向变化率限制，因此150和500均是上限，实际指令可以更低。位置与航向纠偏仍参与控制；TACC/TDEC不保证纠偏叠加后的完整速度矢量或实际电机的加减速度。

1. 更新EIDE构建的配套固件，重新打开上位机。
2. 在“轨迹调参”页点击“500mm/s提速输入”，或加载同目录的`trajectory_settings_500mm_s_20261004.json`。
3. 在轨迹停止、未上传或准备批次时点击“发送全部”；逐项等待STM32回读。确认右侧TVMAX=500、TVARC=150、TACC=600、TDEC=1000及其余项回读一致，再启动路径。

预设按钮、编辑与加载JSON只填输入框，不自动发送。当前12项均为RAM参数，新固件重启恢复这套默认值，原16字段Flash记录不变。旧9项JSON可加载，新三项按默认值补齐。PC模拟使用自己的控制模型，本次提速适用于实机批次执行，不改变GOTO调参或PC模拟速度。

圆弧在进入前按`v² = v_arc² + 2*TDEC*剩余距离`降低前馈，STOP按到站距离制动。每段STOP重新从零起步；中间采样点不停稳。靠近偏差门限时降低前馈，为纠偏留出时间；超限仍按原错误13停车。车体/安全裕量、定位新鲜度、心跳、STOP立即取消和到站真实停稳200ms均保留。离线测试不能证明此前实车错误13已消失。
