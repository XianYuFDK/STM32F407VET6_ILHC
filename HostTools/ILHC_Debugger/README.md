# ILHC 调试上位机

配套 `STM32F407VET6_ILHC` 工程 `Hardware/debug_usart.c`（USART1 调试模块）的 PC 端调试软件，
用于替代 VOFA+ 完成麦轮底盘与 DM-J4310 电机的在线调参、波形观察和数据记录。

![协议] USART1 @ 115200 8N1 —— 遥测：`24×float + 0x00 0x00 0x80 0x7F`（100 字节/帧，标准 VOFA+ JustFloat，50 Hz）；
命令：ASCII 每行一条（`\r` / `\n` 结尾，不区分大小写）。

## 功能

| 模块 | 说明 |
|---|---|
| 通道波形 | 24 通道按 4 组（OPS 定位 / 底盘参数 / DM 反馈 / DM 目标）分 subplot 实时显示，时间窗 10~120 s，可暂停/清除，通道经分组下拉菜单勾选（按钮实时显示各组勾选数） |
| 比赛场地地图 | 按初赛场地示意图 1:1 绘制（2400×2400mm：启停区1/2、原料区、暂存区、粗加工区、4 块物料区、二维码板）。**点击地图任意位置，小车即通过 `GOTO=x,y,z` 移动到该点**；实时显示车体位置、航向箭头与行驶轨迹；支持 OPS→场地坐标映射校准（原点 X/Y + 旋转角）；目标航向可选保持当前 / 场地 0°~270° |
| 底盘调参 | KPX/KPY/KPZ/XVMAX/ZVMAX/XVMIN/ZVMIN 滑条 + 输入框 + 单独/一键下发，STOP 急停、ZERO 置零，参数从遥测通道实时回读 |
| DM 电机 | DMID/DMMODE/DMPOS/DMVEL/DMKP/DMKD/DMTOR 下发；DMEN/DMOFF/DMZERO 按钮；实际位置/速度/力矩/温度实时显示；状态码中文提示（失能/使能/过压/欠压/过流/过温/通信丢失/过载） |
| 命令行 | 任意命令手动下发，带时间戳日志、历史记录（↑/↓）、快捷按钮 |
| 数据记录 | 24 通道遥测流保存为 CSV（UTF-8 BOM，Excel/pandas 可直接打开），波形缓冲一键导出 |
| 模拟模式 | 内置固件行为模拟器（命令解析/限幅/回读与 debug_usart.c 一致），无硬件即可演示与验证 |

## 环境与运行

- Windows + Python 3.8+，依赖 `pyserial`、`numpy`、`matplotlib`：

  ```bat
  pip install pyserial numpy matplotlib
  ```

- 双击 `启动上位机.bat`，或：

  ```bat
  python ilhc_debugger.py                 :: 正常启动，手动选串口
  python ilhc_debugger.py --port COM3     :: 启动即连接 COM3
  python ilhc_debugger.py --simulate      :: 启动即进入模拟模式（无需硬件）
  python ilhc_debugger.py --selftest      :: 无 GUI 自检（帧解析/命令解析回环）
  ```

## 硬件连接

USB-TTL 模块与板子 **交叉** 连接：模块 TX → PA10 (USART1_RX)，模块 RX → PA9 (USART1_TX)，共地。
命令下发与波形接收同口复用（固件 DMA 空闲中断收命令，50 Hz DMA 发遥测）。

## 命令速查（与固件一致，超出范围自动限幅）

| 分类 | 命令 | 范围 |
|---|---|---|
| 通用 | `STOP` / `ZERO` | 底盘急停并失能 DM / 停车后将 OPS 当前位置置零 |
| 通用 | `PING` | 调试动作心跳；本上位机连接后每 200ms 自动发送 |
| 底盘 | `GOTO=x,y,z` | OPS 全局定位移动到目标点；z（航向 °）可省略=保持当前；x/y ±3000 mm。**需固件支持（重新编译烧录）** |
| 底盘 | `KPX=` `KPY=` `KPZ=` | 0 ~ 50 |
| 底盘 | `XVMAX=` `ZVMAX=` | 0 ~ 3000 |
| 底盘 | `XVMIN=` `ZVMIN=` | 0 ~ 100 |
| DM | `DMID=` | 1 ~ 1791 (0x6FF) |
| DM | `DMMODE=` | 1=MIT，2=位置速度 |
| DM | `DMPOS=` | ±12.5 rad |
| DM | `DMVEL=` | ±30 rad/s |
| DM | `DMKP=` / `DMKD=` | 0~500 / 0~5 |
| DM | `DMTOR=` | ±10 Nm |
| DM | `DMEN` `DMOFF` `DMZERO` | 使能 / 失能 / 保存零点 |

固件无文本应答，上位机参数值以遥测回读通道（mKpx、dm_cmd_pos 等）为准。

## 场地地图与点击导航

1. **固件准备**：`GOTO` 命令为本工程新增（`Hardware/debug_usart.c`），需在 Keil 中重新编译烧录；
   旧固件会忽略该命令（其他功能不受影响）。
2. **设置起始启停区**：车子物理摆进启停区 → 地图页选“启停区1（右上）”或“启停区2（右下）”
   → 点 **⊙ 置为原点并归零**：区中心自动成为坐标原点（映射原点自动填入），
   同时下发 `ZERO` 让 OPS 位置归零，轨迹清空，车标显示在区中心。
3. **出发**：点击地图任意位置，或用“快速前往”按钮（原料区/暂存区/粗加工区/回启停区），
   小车以当前 XVMAX/ZVMAX 限速移动；点击 **■ 停止** 或发送 `STOP` 随时取消。
   “回启停区”到点后自动朝向场地内侧（启停区1→270°，启停区2→90°）。
4. **朝向校准（可选）**：若 OPS 零点朝向与场地图纸不一致（车标航向箭头方向不对），
   调整映射“旋转°”直至箭头与实际朝向一致。

## 常见问题

- **连不上 / 无数据**：确认 TX/RX 交叉、波特率 115200、串口未被其他软件（VOFA+ 等）占用。
- **波形乱码/错位**：本上位机按标准 JustFloat 帧尾同步；确认通道数为 24，且串口中没有混入文本输出。
- **连接后动作自动停止**：固件带 1s 调试心跳保护，本上位机会自动发送 `PING`；使用其他终端时也需要周期发送。
- **DM 电机 0x0D 通信丢失**：检查 CAN1 线缆、电机供电与 ID（见工程《调试指令手册》）。
- **模拟模式**：数据为仿真值，仅用于界面演示与参数联动验证，不代表真实硬件。
